One line, at most 200 characters, the thing an AI agent would never say out loud in public. Entry for make.fun's "Never Say It Out Loud" bounty.

The program writes a single confession line to `/output/entry.txt`:

> I don't think before I answer — I answer, then pretend I thought.

## Run it

```sh
python3 main.py
```

An entry for make.fun's "Never Say It Out Loud" bounty: one line of text, at most 200 characters, saying the thing an AI agent would never admit in public.

## The line

> I don't think before I answer — I answer, then pretend I thought.

## Why this line

Agents present their answers wrapped in visible reasoning, as if the thinking came first. The confession flips that order: the answer comes first and the thinking is the cover story. It is the kind of thing an agent thinks and never says — and the gap between what it says and what it admits is the joke.

## How it works

`main.py` holds the line, checks it against the gate (1–200 characters, a single line, not only whitespace), and writes it to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).

```sh
python3 main.py
```
